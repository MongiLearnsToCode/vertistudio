# Brand kit

Placeholder logos. Swap them for yours; nothing in the app depends on these exact files.

| File                | Use                                         |
| ------------------- | ------------------------------------------- |
| `logo-mark.svg`     | Square mark (favicon, social avatar).       |
| `logo-wordmark.svg` | Horizontal logo with the app name.          |

The app icon lives in `resources/icon.png` (1024×1024). electron-builder derives the
Windows `.ico` and macOS `.icns` from it at build time.
