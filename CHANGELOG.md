# Changelog

## [0.1.0] - 2026-10-05

First public release. A free cut of the Desktop App Boilerplate: the app shell, the typed and
validated IPC bridge, settings and OS-encrypted secrets, file and folder access, a Claude client
for the main process, 20 UI components, motion, generators, CLAUDE.md, and unsigned installers for
Windows, macOS and Linux.
